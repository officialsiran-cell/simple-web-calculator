# Simple Web Calculator

## Introduction
The Simple Web Calculator is a web-based software application developed using HTML, CSS and JavaScript. It allows users to perform basic arithmetic calculations through a simple and attractive user interface.

## Features
- Addition
- Subtraction
- Multiplication
- Division
- Percentage Calculation
- Decimal Number Support
- Clear (C) Button
- Backspace Function
- Responsive User Interface

## Technologies Used
- HTML5
- CSS3
- JavaScript
- GitHub
- GitHub Pages

## How to Use
1. Enter numbers using the calculator buttons.
2. Select the required arithmetic operator.
3. Press the equal (=) button to get the result.
4. Use the Clear button to reset the display.
